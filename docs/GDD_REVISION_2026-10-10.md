# GDD revision, 2026-10-10: the forge of an adventurers' guild

Addendum to `Tiny_Blacksmith_GDD_v1.0.md`. The GDD itself is not edited; where this file and the GDD disagree about a
guild run, this file holds. Source: `docs/GUILD_EVOLUTION_SPEC.md`, section 2.2 (the owner's plan of 2026-10-10). How it
is built and what is done: `docs/GUILD_EVOLUTION_PLAN.md`.

**Status.** The owner confirmed the revision on 2026-10-10 as spec 2.2 states it. It changes rules the GDD marks LOCKED;
that is a decision of the owner, not a drift. Every number and every name the revision brings (classes, missions,
charters, relics, enemies, fees, day 20 itself) is PROPOSED.

## Which runs it applies to

Guild mode is a property of a run (plan D1). A run started with a charter is a guild run and plays under the contract
below. A run started without a charter is a classic run and plays under the GDD's original contract, unchanged: same
rules, same draws, same outcomes. A classic run in progress when the update is installed stays a classic run to its end
(spec 16.1); nothing is rewritten under the player.

## What the revision replaces

| Previously LOCKED (GDD v1.0) | In a guild run |
|---|---|
| Only shop actions; the player never equips or directs heroes | Contracted guild members can receive loaned equipment, form a party and take a selected assignment. Ordinary customers remain autonomous |
| The three strongest available champions are always chosen automatically | Three defence places and an automatic recommendation remain; the manager may reserve available guild members for them |
| No end point; only endless survival | Endless play remains. A day-20 charter milestone and an optional successful retirement are added; continuing is a real choice |
| Strong permanent upgrades primarily extend survival | Earned upgrades are preserved; new progression largely unlocks alternative rules, starting choices and optional difficulty |
| All information descriptive, without exact probabilities or formulas | Hidden random odds stay descriptive. Deterministic effect rules, thresholds, costs, timing and trigger limits are shown exactly |
| Every successful craft produces a usable weapon | Kept. Experimental failures become interesting flawed items, never empty rolls |
| Relaxed economy | Ordinary crafting stays affordable. Pressure sits on scarce ingredients, deployments, roster availability and opportunity cost |
| One workshop with panels | The forge-first portrait style and the four destinations are preserved; Town evolves into Guild, with a regional board inside it |

## What is still preserved

Automatic combat; no moving avatar; no reaction or timing minigame; ten base forge energy; overwork carries a next-day
cost; player-controlled days; predictable major sieges; the offline premium model; no ads, IAP or accounts; no runtime
AI; deterministic outcomes; readable and skippable presentation.

Everything else the GDD marks LOCKED and this table does not name stays LOCKED for both kinds of run.
