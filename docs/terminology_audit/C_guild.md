# Terminology audit C: the guild run (facts from code)

Read-only audit, 2026-10-17. Path prefixes: `core/` = `core/src/main/kotlin/com/tinyblacksmith/core/`, `ui/` = `app/src/main/java/com/example/blacksmithproject/ui/`, `app/` = `app/src/main/java/com/example/blacksmithproject/`, `docs/` = repo `docs/`. Numbers are the defaults in `core/config/GuildConfig.kt` and `core/config/BalanceConfig.kt`. "Display" quotes the player-facing string. Concepts audited: **133** table rows (each charter, opening, quest type, modifier, trait, speciality, bond, preparation, law, rank, guild visitor and candidate term counted separately).

End Day order that several rows depend on (`core/engine/GameEngine.kt:419-446`): step 1 the planned party leaves (`Missions.commit`, :422), step 4 the party's stage is fought (`Missions.advance`, :432), then members at home rest or train (`GuildOps.homeDay`, :434), step 7 the siege (:441).
