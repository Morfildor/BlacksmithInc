Assets/Icons
Interface icons: resources, navigation, settings, rarity and flaw badges, hero markers.

File rules: PNG with a transparent background unless the piece is a full scene or a framed portrait tile.
Name each file <id>.png using the IDs below, or drop a sheet plus a manifest.json that names its cells.
Any resolution is fine if it is a clean multiple of the listed in-game size; native pixel size is best.

Status as of 2026-10-17. Pieces already delivered and in the game are not listed as wanted: do not resend them.
Redrawn 2026-10-17 with Retro Diffusion (rd_pro__fantasy) as one set at about one art pixel per displayed dp: status icons and
badges 24 px, actions and navigation 32 px, purse and siege traits 40 px, visitor 48 px, markers 16 px
(docs/UI_ART_REVAMP.md). The sizes below are the earlier ones.
