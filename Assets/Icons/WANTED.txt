Assets/Icons
Interface icons: resources, navigation, settings, rarity and flaw badges, hero markers.

File rules: PNG with a transparent background unless the piece is a full scene or a framed portrait tile.
Name each file <id>.png using the IDs below, or drop a sheet plus a manifest.json that names its cells.
Any resolution is fine if it is a clean multiple of the listed in-game size; native pixel size is best.
